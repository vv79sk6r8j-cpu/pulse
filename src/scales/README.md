# Шкалы PULSE 0.4

Каждый клинический инструмент содержит собственные критерии и атрибуты страницы: `category`, `title`, `subtitle`, `shortTitle`, `cardTitle`, `instruction`, `catalogDescription`, `disclaimer`, `sourceLabel`, `sourceUrl` (либо отдельную ссылку на источник).

- `gcs.tsx` — GCS.
- `rass.ts` — RASS (критерии); интерфейс в `ScaleTool.tsx`.
- `qsofa.ts` — qSOFA (формула); интерфейс в `ScaleTool.tsx`.
- `asa.tsx` — ASA PS I–VI и E.
- `four.tsx` — FOUR (E/M/B/R).
- `sofa.tsx` — оригинальная SOFA, шесть органов.

Общие визуальные компоненты можно переиспользовать, но тексты, формулы, пороги, ограничения и источники должны находиться рядом с соответствующим инструментом. Изменения клинических критериев требуют сверки с первоисточниками и тестирования.
