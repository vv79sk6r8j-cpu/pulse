# Шкалы PULSE
Каждая шкала хранит собственные клинические критерии и источники в отдельном файле.
- `gcs.tsx` — интерактивная шкала GCS.
- `rass.ts` — критерии RASS; интерфейс в `ScaleTool.tsx`.
- `qsofa.ts` — формула qSOFA; интерфейс в `ScaleTool.tsx`.

Общий интерфейс допустим, но критерии и вычисления не должны зависеть от других шкал.
Перед изменением баллов, порогов и интерпретаций сверяйте первоисточники.

## Обязательные атрибуты страницы шкалы
Каждая шкала должна хранить рядом с критериями: категорию (`category`), полное название (`title`), международное название (`subtitle`), краткое обозначение (`shortTitle`), заголовок формы (`cardTitle`), инструкцию (`instruction`, если применима), описание в каталоге (`catalogDescription`), ограничения (`caution`) и источник (`sourceLabel`, URL). Общий UI только отображает эти поля; не дублируйте заголовки в `App.tsx`.
