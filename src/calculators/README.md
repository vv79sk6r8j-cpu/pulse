# Калькуляторы PULSE 0.4

- `ibw.tsx` — идеальная масса тела по Devine.
- `renal.tsx` — CKD-EPI 2021 (eGFR) и Cockcroft–Gault (CrCl).
- `infusion.tsx` — расчёт мл/ч из заданной пользователем дозы, массы и конечной концентрации (норадреналин, адреналин, допамин, универсальный режим).

Каждый калькулятор хранит собственные атрибуты страницы, формулу, ограничения, источники и функцию копирования результата. Не подставляйте схемы разведения и назначенные дозы без согласования. Перед клиническим использованием требуются тесты граничных значений и независимая проверка расчётов.
