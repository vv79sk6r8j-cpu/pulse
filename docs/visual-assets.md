# Реестр визуальных ресурсов PULSE
Целевая структура и правила: [Design Guide](design-guide.md). Реестр начальный, не полная инвентаризация.

| ID | Назначение | Текущее расположение | Целевое расположение | Источник / права | Статус |
|---|---|---|---|---|---|
| brand-mark | Фирменный знак | src/App.tsx, Mark | src/components/icons/PulseMark.tsx | PULSE; подтвердить происхождение | миграция ожидается |
| brand-wordmark | Логотип в меню | src/App.tsx, sidebar-wordmark | public/assets/brand/pulse-wordmark.svg | PULSE; подтвердить происхождение | миграция ожидается |
| pocus-icon | Навигация POCUS | src/App.tsx, PocusIcon | src/components/icons/PocusIcon.tsx | собственный SVG по визуальным референсам; лицензии референсов не подтверждены | проверка прав и стенда ожидается |
| lucide-ui | Стандартные графемы | lucide-react | src/components/icons/index.ts | проверить LICENSE установленной версии | миграция ожидается |

## Новые записи
ID, назначение, путь, alt (или декоративный статус), подпись, автор, источник/URL, лицензия, дата, версия, статус клинической и юридической проверки. Не публиковать клинические материалы с идентификаторами пациентов. Для ресурсов без подтверждённых прав предусмотреть замену.

## Миграция
Инвентаризировать все существующие файлы и ссылки, затем переносить с обновлением импортов и URL. Проверять Vite BASE_URL, preview и production. Для Wagtail сохранить соответствие ID и записей CMS; пользовательские изображения хранить в media, системные в static. Не удалять исходные файлы до проверки ссылок.
