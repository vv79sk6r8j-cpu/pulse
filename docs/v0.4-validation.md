# Валидация всех клинических инструментов PULSE 0.4
Обязательное требование перед релизом.
- Красный: отсутствует обязательный параметр после попытки расчёта, неверный формат, математически недопустимое значение или нарушение установленной области применимости инструмента. Не считать неизвестные необязательные данные нулём.
- Оранжевый: вероятная ошибка ввода, экстремальное, но возможное значение. Не блокировать расчёт, не изменять введённое значение.
- Для каждого параметра централизованно описать единицу, преобразование, обязательность, математические ограничения, предупредительные границы, источник, популяцию и статус проверки. Не подменять границы правдоподобия референсами или клиническими порогами.
- Пороги 30/1000 мкмоль/л для креатинина — пример владельца, не утверждённые границы. Не публиковать как доказательные. Пересмотреть блокирующие ограничения креатинина в renal.
- Проверить все числовые и категориальные поля GCS, RASS, qSOFA, ASA, FOUR, SOFA, KDIGO, IBW, renal, infusion; контекстные зависимости, единицы, пропуски, граничные значения. Для доз препаратов не вводить универсальные терапевтические границы без предметного источника.
- Предупреждения отображать после попытки расчёта или завершения ввода, с текстом и доступным обозначением, не только цветом.
- До релиза утвердить реестр порогов и тесты; при отсутствии обоснования не выдумывать числовой порог.
