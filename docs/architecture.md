# Архитектура PULSE

PULSE — статическое клиентское приложение React/Vite, опубликованное на GitHub Pages. Это **модульная архитектура по предметным областям**, а не отдельные серверные микросервисы: каждый модуль собирается в единый фронтенд. Такое разделение позволяет редактировать и тестировать материалы независимо, не усложняя инфраструктуру.

## Иерархия

```text
src/
├── App.tsx                 # оболочка приложения и навигация
├── articles/               # теория: один материал = один Markdown-файл
│   └── tela.md
├── scales/                 # клинические шкалы
│   ├── gcs.tsx              # GCS: данные и интерфейс
│   ├── rass.ts              # RASS: критерии и источник
│   ├── qsofa.ts             # qSOFA: формула и источник
│   └── ScaleTool.tsx        # общий UI для RASS и qSOFA
├── calculators/            # отдельный файл для каждого калькулятора
├── pocus/                  # отдельный протокол POCUS в каждом файле
├── documents/              # шаблоны медицинских документов
└── references/             # справочные материалы
```

## Принципы

1. Один клинический инструмент — отдельный файл с его данными и формулами; общие компоненты UI можно переиспользовать.
2. `App.tsx` отвечает за навигацию, а не за клинические расчёты.
3. Источники, единицы и ограничения документируются рядом с клинической логикой.
4. Для изменения медицинского текста редактировать файл инструмента; формулы и пороги менять только после проверки.
5. Разделы `calculators`, `pocus`, `documents`, `references` пока содержат README, но не опубликованные инструменты.
6. Тестовый стенд собирается из `feature/v0.4-scales-calculators`; production из `main`.

В перспективе при необходимости можно выделить серверные API-сервисы, но сейчас они не нужны для автономных шкал и справочников.
