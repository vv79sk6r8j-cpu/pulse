# Регламент управления стандартами PULSE

| Реквизит | Значение |
|---|---|
| Версия стандарта | 0.1 |
| Дата создания | 27.11.2026 |
| Дата изменения | 27.11.2026 |
| Валидация | Не пройдена |
| Дата валидации | — |
| Валидатор | — |

Все внутренние стандарты хранятся в standards/. Каждый стандарт содержит в шапке собственную версию, дату создания, дату изменения, признак валидации, дату валидации и валидатора. Версия стандарта независима от версии продукта. После создания или содержательного изменения AI создаёт отдельную GitHub issue на валидацию человеком (Human), со ссылкой на документ и версией. До явного утверждения владельцем проекта статус — Не пройдена. После утверждения фиксируются дата, валидатор и статус Пройдена. При содержательном изменении повышается версия, обновляется дата изменения, сбрасывается признак валидации и создаётся задача повторной проверки. История сохраняется в Git. Закрывать задачу валидации только после явного утверждения владельцем проекта.
