# PULSE

Клинический справочник для анестезиологов-реаниматологов.

## Локальный запуск

```bash
npm install
npm run dev
```

## Сборка

```bash
npm run build
```

MVP: адаптивный интерфейс, навигация, поиск по разделам и калькулятор GCS. Теория, POCUS, документы и справочники пока являются заготовками. Инструмент не заменяет клиническое решение.
