# История версий PULSE

Здесь фиксируются изменения приложения: **версия → статус → что добавлено, изменено или исправлено**. Новые версии располагаются сверху.

## [0.3.0] — 23 ноября 2026
**Статус:** код версии 0.3 перенесён в `main`; успешность последнего развёртывания GitHub Pages требует отдельного подтверждения.

### Добавлено
- Первая статья в разделе «Теория»: «Тромбоэмболия лёгочной артерии (ТЭЛА)».
- Хранение текста статьи в Markdown (`src/articles/tela.md`) для последующего редактирования в репозитории.
- Отображение структурированных таблиц, списков и заголовков в статье.
- Указание типа материала «Пособие» и библиографического источника с ссылкой на публикацию.

### Исправлено и улучшено
- Отображение таблиц с критериями Wells и Geneva, включая заголовки и строки.
- Форматирование перечней критериев и противопоказаний в виде списков.
- Удалена служебная формулировка «без плашки КР или МР» из интерфейса статьи.
- Уточнено правило классификации материалов: «Пособие», «Теория», «Клинические рекомендации», «Методические рекомендации».

**Примечание:** внесение кода в `main` само по себе не подтверждает успешное развёртывание сайта. Проверка production-деплоя ведётся отдельно.

## [0.2.0] — 23 ноября 2026
**Статус:** изменения перенесены в `main` для публикации на GitHub Pages.

### Добавлено
- Разные иконки для ярлыков iPhone: PULSE и PULSE TEST, с автоматической генерацией PNG для Apple Touch Icon.
- Раздельные страницы: главная → каталог раздела → отдельный инструмент GCS.
- Поиск по инструментам внутри раздела «Шкалы и расчёты».
- Интерпретация результата GCS и кнопка копирования готовой записи.
- Единые элементы навигации и более заметная нижняя панель на смартфоне.
- Новая главная страница с приветственным блоком и быстрым переходом к калькуляторам.
- Нижняя навигация и выдвижное меню для мобильных устройств.
- SVG-знак PULSE с условным ЭКГ-комплексом.
- Статусы наполнения разделов и сообщения для пока не готовых материалов.

- Форма «Сообщить об ошибке» с сохранением текста в GitHub и уведомлением через Telegram-бота.
- Раздел «Контакты» со ссылкой на Telegram автора.

### Изменено
- Приветственный блок уменьшен и оставлен только на главной; калькулятор GCS убран с главной страницы.
- Дизайн карточек, поиска, верхней панели и навигации в единой тёмно-бирюзовой палитре.
- Оформление калькулятора GCS без изменения принципа расчёта.
- Адаптивная компоновка для узких экранов и прокрутка мобильного меню с учётом панели Safari.
- Интерпретация GCS по согласованной таблице состояний сознания.

**Проверка:** тестовая версия проверена на iPhone; отправка обращения, сохранение в GitHub и доставка уведомления Telegram подтверждены. Статус итоговой production-сборки проверяется отдельно.

## [0.1.0] — первая опубликованная версия
**Статус:** опубликована на GitHub Pages.

### Добавлено
- Основа приложения на React, TypeScript и Vite.
- Главная страница, боковая навигация и адаптивная компоновка.
- Разделы: «Теория», «Шкалы и расчёты», «POCUS», «Документы», «Справочники».
- Поиск по названиям и описаниям разделов.
- Интерактивная шкала комы Глазго (GCS): компоненты E, V, M и сумма баллов.
- Предупреждение об ограничениях клинического использования.
- Автоматическая сборка и публикация через GitHub Actions / Pages.

**Ограничения:** кроме GCS клинические разделы пока представлены заготовками.

---

### Правила ведения
- **PATCH (0.2.1):** исправления без новых функций.
- **MINOR (0.3.0):** новые функции, разделы и заметные улучшения интерфейса.
- **MAJOR (1.0.0):** крупный стабильный релиз.
- Незавершённые изменения отмечаем как «в разработке»; после публикации фиксируем дату релиза и результат проверки.
